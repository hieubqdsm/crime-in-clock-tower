# Online foundation — websocket server + options UI

## Description
First multiplayer slice toward the online party game. A tiny Python websocket
server (committed in this repo) keeps a room of players; the game gains an
Options UI with a server-URL field. Player identity persists in the
BROWSER's localStorage, so each browser is its own character, while a second
tab of the same browser takes over that character instead of spawning a
duplicate (server-side takeover by player id).

## Acceptance criteria (when is it done)
- [ ] tools/server/server.py: join/world-state protocol, takeover by id, 12 Hz tick
- [ ] NetClient (in-game): connect/poll/JSON, own-position upload, remote-state apply
- [ ] RemotePlayer: mannequin avatar with interpolation + Walk/Idle + name Label3D
- [ ] Options UI (press O): server URL LineEdit + connect/disconnect + status
- [ ] Player id persisted in browser localStorage (desktop: user:// file)
- [ ] Headless e2e auto-test: 2 clients join one local server, takeover works
- [ ] Deployed to Pages; localhost server reachable from the https build
