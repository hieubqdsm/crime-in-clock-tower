# Wooden mannequin isometric room movement

## Description
First playable vertical slice of the game: a wooden artist mannequin model
(built in Blender, exported as glb) that the player moves around a closed 3D
room, viewed from a fixed isometric orthographic camera. This establishes the
core presentation (3D isometric) and locomotion every later feature builds on.

- [x] Wooden mannequin 3D model (glb) in the project and used by the player scene
- [x] Player scene: CharacterBody3D + collision, moves with WASD/arrows
- [x] Room scene: floor + 4 walls with collision (closed play space)
- [x] Isometric orthographic camera; movement is camera-relative
- [x] Main scene composes Room + Player + camera + lighting

### Web + browser smoke test (render + real input verification)
The headless test covers logic only; the web build verifies the actual render
and the input pipeline in a real browser (ZCode in-app browser, via the
browser-use skill / `node_repl`):

```
godot --headless --path . --export-release "Web Smoke Test"   # → build/web/
python -m http.server 8741 --directory build/web
```

The player pushes telemetry via `JavaScriptBridge.eval("window.gameState={...}")`
(web-only, `scenes/player/player.gd::_push_web_state`). Procedure: open
`http://127.0.0.1:8741/index.html`, click the canvas once to give the webview
focus, then dispatch keyboard events **on the canvas element** (Godot's web
input ignores document-level events):

```js
document.querySelector('canvas').dispatchEvent(
  new KeyboardEvent('keydown', {code:'KeyW', key:'w', bubbles:true}))
```

Result (2026-09-09): **5/5 PASS** — W held 1 s moved the mannequin 2.24 m
up-screen (dx=dz=-1.58, 2.2 m/s), `Walk` anim while moving, idle + zero
velocity after release, on floor. Screenshot of the live render verified the
isometric room + mannequin visually: `docs/evidence/f001-web-smoke.png`.

Gotchas discovered (do not relearn):
- `document.hasFocus()` is false until a REAL click hits the canvas (CUA click
  works); Godot drops all keyboard input while unfocused.
- Synthetic `KeyboardEvent` must be dispatched on the **canvas**, not
  document/window (which is where they are merely observed).
- Export target dir must exist before `--export-release` (Godot errors out).
