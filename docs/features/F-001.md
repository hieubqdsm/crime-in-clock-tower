# Wooden mannequin isometric room movement

## Description
First playable vertical slice of the game: a wooden artist mannequin model
(built in Blender, exported as glb) that the player moves around a closed 3D
room, viewed from a fixed isometric orthographic camera. This establishes the
core presentation (3D isometric) and locomotion every later feature builds on.

## Acceptance criteria (when is it done)
- [x] Godot project exists (`project.godot`), boots headless without errors
- [x] Wooden mannequin 3D model (glb) in the project and used by the player scene
- [x] Player scene: CharacterBody3D + collision, moves with WASD/arrows
- [x] Room scene: floor + 4 walls with collision (closed play space)
- [x] Isometric orthographic camera; movement is camera-relative
- [x] Main scene composes Room + Player + camera + lighting
