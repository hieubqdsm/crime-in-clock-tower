# Proximity voice chat

## Description
The party game's core: talk (push-to-talk V), only players NEAR you hear you.
Mic → 16 kHz mono PCM chunks over the existing websocket (binary frames) →
server relays → receiving clients play through per-remote AudioStreamGenerator
with the same inverse-square falloff as F-002's tokens.

## Acceptance criteria (when is it done)
- [x] server relays binary voice frames sender→everyone-except-sender
- [x] VoiceCapture: mic on a silent capture bus, 100 ms chunks while V held
- [x] RemotePlayer: generator playback + distance gain + speaking indicator
- [x] Options: mic enable toggle (+ permission flow on web)
- [x] Headless e2e: fake PCM travels client→server→client, playback fed
- [ ] Web: two browsers (pending tester ears + mic permission) actually talk and hear with distance falloff
